# M2 replay scenarios

**Scenario author:** trade-rs-m2-scenarios crewmate (written before M2 production code).

- Replaying identical raw command bytes in fresh processes produces identical complete event bytes.
- The checked-in prevention fixture produces fill, resting-maker cancellation, fill, and one
  completion in that exact order for command 4.
- A self-only market ends unfilled and a self-only executable limit rests; neither self maker
  trades or causes rejection.
- Valid command order is global while books remain symbol-isolated. Direct M1 outcomes,
  effects, typed errors, and snapshots agree with replay.
- Malformed syntax, noncanonical JSON, unknown/duplicate fields, unsupported versions,
  invalid registry ordering, invalid UTF-8, BOM, CRLF, blank records, and integer range errors
  fail without replacing an existing output file.
- Unknown-symbol, zero-quantity, duplicate-ID, and missing-order precedence emits exactly one
  rejection and no effects for that command; later valid commands still run.
